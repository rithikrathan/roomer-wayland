# way to increase and decrease the rows and cols in table tool

- STATUS: CLOSED
- PRIORITY: 100
- TAGS: better

Added keyboard controls while dragging the table tool to adjust dimensions with live preview:
- Up Arrow or 'W': increase rows
- Down Arrow or 'S': decrease rows (minimum 1)
- Right Arrow or 'D': increase columns
- Left Arrow or 'A': decrease columns (minimum 1)
