Dual swatch sets implemented across all tools:
- Set 1 = (Line 1, Fill 1), Set 2 = (Line 2, Fill 2).
- Colors are globally shared across Pen, Highlighter, Line, Arrow, Polygon, N-gon, Circle, Table, Step Badge, and Text.
- Pressing 'X' (or clicking '<>' in the toolbox) swaps between Set 1 and Set 2.
- Clicking any swatch opens Yad to update that specific slot and activates the set.
